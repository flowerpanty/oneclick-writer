입력 방식 UI — 어떤 탭 구조가 맞나요?

3가지 입력 모드를 어떻게 보여줄지 선택해주세요

입력
📝 주제
🔗 URL
📄 내 글/내용
요즘 두쫀쿠가 유행한다던데…
일상 대화처럼 입력해도 됩니다

A. 탭 방식

주제 / URL / 내 글 탭으로 구분. 탭 클릭하면 입력란 바뀜.

입력
📝 주제 입력
🔗 URL
📄 내 글/내용
URL이나 긴 텍스트를 붙여넣으면 자동으로 모드가 바뀝니다

B. 통합 입력창 (자동 감지)

텍스트창 하나. URL 붙여넣으면 URL모드, 긴 글 붙여넣으면 내용모드로 자동 전환. 심플.

입력
주제 또는 URL 입력…
📄 내 글/수집 내용 붙여넣기 (선택)
없으면 AI가 직접 리서치합니다

C. 기본 + 선택적 추가 입력

주제/URL 기본 입력 + "내 글 붙여넣기" 영역 선택 추가. 명확한 역할 구분.

클릭하거나 터미널에 A/B/C로 답해주세요.
