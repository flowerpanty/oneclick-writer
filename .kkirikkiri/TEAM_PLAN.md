## 작업 요구사항 (유저 인터뷰 요약)
사용자가 원하는 것:
1. 주제/내용을 던지면 → 리서치 → 블로그 글 자동 작성
2. 블로그 글의 어투/구조 유형을 리서치해서 프리셋 몇 가지 만들기
3. 프리셋을 동적으로 선택/생성 (고정값 아님)
4. 온보딩 포함 (API 키 세팅 등 초기 설정)
5. 레퍼런스 블로그 링크/내용 가져오기 (네이버 블로그 등)
6. 네이버 블로그 우회 접속 → Playwright 등 활용 검토
7. 최종 결과물: 전략 + 구현 설계서 (바로 만들기 시작할 수 있는 청사진)

## 주요 결정사항
1. 스킬 방식 채택 (에이전트 불필요) — 전원 동의
2. 프리셋 5개 유지, SEO는 공통 레이어로 분리
3. 동적 선택 = 규칙 기반 추천 + 텍스트 신호 분석 + 사용자 확인
4. 리서치를 서브에이전트로 위임 (컨텍스트 보호)
5. 네이버 블로그: 3단계 계층적 폴백 (WebFetch → 모바일 URL → 붙여넣기), Playwright는 MVP 배제
6. 온보딩 최소화 (API 키 없이 WebSearch로 동작)
7. 기존 서버와 독립적으로 설계 (참조만 활용)
